The task

The hippocampus is a small structure in the brain's temporal lobe. Its volume and shape are biomarkers for Alzheimer's disease, epilepsy and schizophrenia, but manual tracing is slow and varies between raters. Each case is a cropped T1-weighted MRI volume around one hippocampus. The images carry realistic MRI noise and some training labels are wrong at the boundaries: your model has to be robust to both. Your model must label every voxel as anterior (head), posterior (body + tail) or background.

How it works

1 · Train locally

Fork the repo. Images and labels are in data/public/. Use any framework or method (nnU-Net, MONAI, your own). A small 3D U-Net starter is included.

2 · Predict the test set

Segment the 52 volumes in data/public/imagesTs/. Their labels are hidden and encrypted.

3 · Submit by Pull Request

One command packs and encrypts your masks. Open a PR with the two generated files.

4 · Get scored

GitHub Actions decrypts and scores your submission, comments the result on your PR and updates this leaderboard within minutes.

Source

Data comes from Task04_Hippocampus of the Medical Segmentation Decathlon (Vanderbilt University Medical Center, mono-modal MRI, licence CC-BY-SA 4.0). The official MSD test labels were never released, so this competition splits the 260 labelled MSD cases into train / validation / hidden test with a fixed seed. Test images are renamed to anonymous ids.

Noise: the twist

This is a robustness benchmark. The data is deliberately corrupted:

NoiseApplied toDetails
MRI bias fieldall imagessmooth multiplicative intensity drift, up to about ±25%
Rician noiseall imagesMR magnitude noise. Sigma is 2-10% of the 99th-percentile intensity and varies per case
Label noise25% of training labels (not disclosed which)each class randomly eroded or dilated by 1 voxel
Cleanvalidation + hidden test labelsso scores measure true error

Primary metric: mean Dice

For every test case and each foreground class c ∈ {anterior, posterior}:

Dice_c = 2·|P_c ∩ G_c| / (|P_c| + |G_c|)        (1.0 if both are empty)

Each class's Dice is averaged over the 52 test cases, then the two classes are averaged. Higher is better.

Tie-break: Normalised Surface Distance (NSD)

NSD is the second MSD metric. It is the fraction of boundary voxels of the prediction and of the ground truth that lie within 1 mm of the other surface. It rewards accurate boundaries. It is averaged the same way as Dice and is used only to break ties.

Submit in 4 steps

  1. Fork the repository and clone your fork, then run pip install -r requirements.txt.
  2. Predict every test case and save one label map per case as <case_id>.nii.gz (e.g. test_001.nii.gz), with the same shape as the image and values in {0, 1, 2}.
  3. Package and encrypt: 
    python starter/make_submission.py --pred-dir runs/my_model/test \
    --team my_team --run-id unet_v1 --author-type human \
    --model "3D U-Net" --notes "CE + Dice loss, flip TTA"
    This checks your masks with the official validator and writes submissions/inbox/my_team/unet_v1/predictions.npz.enc and metadata.json.
  4. Open a Pull Request to main that contains only those two files. The bot scores it, comments your result and closes the PR. You do not need to merge it.

Rules

SubmissionsAt most 3 scored runs per team. Each run needs a new run_id. Your best run counts.
DataTrain only on data/public/. Do not use the original, clean MSD release in any way: not to recover test labels and not to replace the noisy training data. Pre-trained weights from other datasets are allowed if you disclose them in notes.
HonestySet author_type truthfully: human, llm (pipeline fully written by an LLM agent) or hybrid.
Pull RequestsA submission PR may only add the two files in submissions/inbox/<team>/<run_id>/. Anything else is rejected automatically.
No manual labellingTest predictions must come from an automatic method.
